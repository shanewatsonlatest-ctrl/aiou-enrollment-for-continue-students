# AIOU Continuing Students Enrollment Guide

Yeh ek Streamlit app hai jo AIOU (Allama Iqbal Open University) ke continuing students ke liye
enrollment process, fee guide, dates aur FAQs deti hai.

## Files
- `app.py` — main app code
- `requirements.txt` — dependencies

## Deploy kaise karein
1. GitHub par naya repo banayein (public), naam rakhein: `aiou-enrollment-guide`
2. `app.py` aur `requirements.txt` dono files usme upload karein
3. [share.streamlit.io](https://share.streamlit.io) par GitHub account se login karein
4. "New app" par click karein → apna repo select karein → Main file: `app.py`
5. Deploy dabayein — 1-2 minute me app live ho jayegi
